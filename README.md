# PhotoBoy - Game Boy Photo Converter

A web application that converts photos into authentic Game Boy-style images using pure JavaScript. Experience the nostalgia of the original Game Boy's iconic green display and pixelated graphics.

## Features

- Upload any photo and convert it to authentic Game Boy style
- Realistic Game Boy-inspired user interface
- Original Game Boy color palette and pixelation
- Scanline effect for authentic retro feel
- Share your creations directly from the app
- Download your converted images
- Responsive design that works on mobile and desktop
- Works offline
- No server required

## Setup

1. Simply open the `index.html` file in your web browser
2. That's it! No installation or setup required

## Usage

1. Click "SELECT PHOTO" to choose an image
2. Click "CONVERT" to process the image
3. View the original and Game Boy versions side by side
4. Use the "SAVE" button to download your creation
5. Use the "SHARE" button to share your image (supports modern sharing APIs)

## Requirements

- Modern web browser (Chrome, Firefox, Safari, Edge)
- No additional software or dependencies needed

## How it works

The application uses the HTML5 Canvas API to:
1. Load the uploaded image
2. Convert it to the original Game Boy's 4-color palette
3. Apply pixelation for that authentic retro look
4. Add scanlines for the classic Game Boy screen effect
5. Display the result alongside the original image
